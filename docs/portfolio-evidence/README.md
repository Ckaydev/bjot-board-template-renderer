# Portfolio evidence

This folder documents the current renderer with the built-in synthetic Chemistry lesson.

- `sample-input.json` contains the editor values used for the demonstration.
- `sample-output.png` was downloaded from the running application through its **Download PNG** action.
- `../../public/og.png` is the repository's social preview and project overview.
- `validation.md` records the checks run against this clean export.

The sample contains no student or client information. BJOT logos, public business contact numbers, and the public website address are part of the product template itself.
